SkillSphere 🌿

A Personal Portfolio and Learning Progress Dashboard

SkillSphere is a Flask-based portfolio project that brings together personal information, technical skills, 
featured projects, achievements, and learning progress in one place.

✨ Features

- Home: Personal introduction and portfolio overview
- About: Information about the developer
- Skills: Technical skills showcase
- Projects: Featured projects with preview images
- Achievements: Achievements and milestones
- Progress: Learning progress tracking and analytics
- Contact: Contact form and relevant links
- Analytics: Data analysis, numerical analysis, and visualizations using Python libraries

🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Pandas
- NumPy
- Matplotlib

🚀 Getting Started

1. Clone the repository

git clone https://github.com/pytgvc/SkillSphere.git
cd SkillSphere

2. Create a virtual environment

python -m venv venv

Activate it:

Windows

venv\Scripts\activate

macOS / Linux

source venv/bin/activate

3. Install dependencies

pip install -r requirements.txt

4. Run the application

python app.py

Open the local URL shown in the terminal in your browser.
